🔥 Firebase 연결

연결하면 다른 기기·OBS에서도 후원 순위가 실시간으로 똑같이 보여요.
연결 안 됨
처음 한 번만 하면 돼요
  1. Firebase 콘솔 → 빌드 → Firestore Database → 데이터베이스 만들기
  2. 규칙 탭에 아래 내용을 붙여넣고 게시
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /overlay/main { allow read, write: if true; }
  }
}
